# Настройка окружения (Windows, PyCharm)

## Очистить старые пакеты

В терминале PyCharm (venv активирован):

```
pip uninstall django asgiref sqlparse Pillow opencv-python -y
```

Если не уверен что установлено — сначала посмотри:
```
pip list
```

---

## Установить новые пакеты

```
pip install -r requirements.txt
```

Установится:
- `pywebview` — десктопное окно с HTML/JS
- `opencv-python-headless` — OpenCV без Qt (обработка изображений)
- `numpy` — числа и массивы
- `pytest` — тесты
- `pyinstaller` — сборка .exe

---

## Запуск приложения

```
python main.py
```

Откроется окно приложения. При первом запуске создаётся папка `data/` рядом с проектом.

---

## Запуск тестов

```
python -m pytest tests/ -v
```

Все тесты должны пройти. Тесты используют фикстуры из `tests/fixtures/` и не требуют запущенного приложения.

---

## Сборка .exe

На Windows установите Python 3.10 или новее с Python Launcher (`py`) или
добавьте `python` в PATH. Запустите двойным щелчком `build_exe.bat` в корне
репозитория. Интернет нужен для установки зависимостей при первой сборке.

Скрипт создаёт отдельное окружение `.build-venv`, устанавливает зависимости из
`requirements.txt`, запускает Python-тесты и собирает приложение через
`app.spec`. При ошибке любого шага сборка останавливается. Существующее
окружение разработки `venv` не используется. Повторный запуск использует
то же окружение сборки.

Перед повторной сборкой закройте приложение. Переносить папки вручную не нужно:
скрипт сначала собирает новую версию во временной папке, переносит в неё
сохранённые данные и только затем заменяет `dist\optical_analyzer\`.
Прежняя версия целиком остаётся в `dist\backups\` в отдельной папке с датой
и уникальным суффиксом. Резервные копии автоматически не удаляются.
Если установка зависимостей, тесты, упаковка или копирование данных завершатся
ошибкой, предыдущая версия останется на месте. Данные из старого расположения
`optical_analyzer\data\` переносятся в используемое новой сборкой `_internal\data\`.

Для запуска из терминала без ожидания нажатия клавиши:

```bat
build_exe.bat --no-pause
```

Или напрямую: `py -3 scripts\build_exe.py`. Сборка Windows выполняется
на Windows; запуск Python-скрипта на другой ОС завершится с объяснением.

Результат: `dist\optical_analyzer\optical_analyzer.exe`  
Для переноса приложения скопируйте **всю папку** `dist\optical_analyzer\`,
включая `_internal`, на совместимый Windows-компьютер. Отдельная установка
Python на нём не нужна. Для окна приложения требуется WebView2 Runtime.

## Проверка измерений и сегментации

Измерения выполняются по контурам до отрисовки линий и номеров. Линейные
размеры выражаются в мкм, площадь — в мкм² при корректно выбранной калибровке.
Старые исследования сохраняют прежние результаты до повторного анализа.
Пустая или некорректная калибровка не допускается к измерениям.

В новом анализе по умолчанию выбирается режим «Автоматически». На цветном фоне
частицы выделяются по отличию цветовых компонент Lab от фона по краям кадра.
Так светлые зёрна на синей подложке выделяются без превращения подложки в частицы.
Для нейтрального фона определяется полярность яркости и порог Оцу; плавный линейный
перепад освещения корректируется, если края кадра подтверждают такую модель фона.
Сегментация выполняется по исходному снимку: усиление контраста остаётся отдельным
предпросмотром и не меняет измеряемую границу.

В «Анализе» раскройте «Выделение частиц». Доступны автоматический режим,
светлые/тёмные частицы и цветной фон. Ручные светлый и тёмный режимы используют
общий порог яркости; они требуют ровного освещения. Минимальная площадь задаётся
в пикс², рядом показан эквивалентный диаметр порога в мкм по выбранной калибровке.
По умолчанию исключаются области площадью не более 100 пикс² и частицы на краю
кадра. Под снимком показаны метод, число найденных и исключённых областей.

У цветного фона небольшой слабый ореол иногда соединяет целое зерно с краем
снимка. Перед исключением проверяются узость контакта и контраст; отделяются
только слабые участки, связанные с краем, если они занимают не более 3% маски
зерна и после удаления остаётся один целый контур внутри снимка. Это не
восстанавливает обрезанные части.
Если контакт с краем остаётся, фрагмент исключается из измерений и показывается
оранжевым в режимах «Контуры» и «Результат распознавания». Красные контуры
с номерами относятся к измеренным частицам. У старых сохранённых изображений
оранжевая отметка появится после повторного расчёта.

Разделение узких соединений по умолчанию включено. Его можно выключить в разделе
«Выделение частиц». Сохранённый явный выбор восстанавливается при открытии
исследования; для старых исследований без настроек новый расчёт использует
включённое разделение.
Проверяется перешеек между внутренними областями частиц, затем области растут
по карте толщины внутри исходной маски. Фон между зёрнами сохраняется фоном;
мелкие присоединённые фрагменты получают отдельные контуры. Порог площади
применяется после разделения: отсеянный фрагмент не прибавляется к крупному зерну.
Отключённое разделение оставляет соединённые области одним объектом.
Это эвристика: она не восстанавливает скрытую площадь
перекрывающихся зёрен. Сравнивайте обводку до и после; для надёжных измерений лучше
разложить частицы отдельно. Нужны резкость и равномерное освещение: сложный фон,
блики, тени и расфокусировка могут менять границу частицы.

Изменение настроек выделения сбрасывает прежние измерения и требует нового
расчёта. Параметры и диагностика сохраняются в `data/research/<id>/analysis.json`
вместе с исследованием. Старые исследования без этого файла открываются с прежними
числами; настройки их исходного расчёта отмечены как неизвестные.

Сравнить прежний фиксированный порог 127, прежний Otsu и новый автоматический
режим на тестовых сценах и фотографиях:

```bash
python scripts/compare_segmentation.py --output comparison
```

В выбранной папке появятся metrics.json и изображения сравнения. Ошибки размеров
вычисляются только для синтетических фигур с известными размерами. Для фотографий
без эталонной разметки число объектов не является оценкой точности.

Калибровка требует не менее трёх согласованных интервалов между штрихами.

В «Настройках» выберите микроскоп слева или нажмите «Добавить».
В его карточке найдите камеры, выберите устройство, проверьте видео и отдельный
тестовый снимок, затем сохраните привязку. Индекс можно указать вручную
в дополнительном разделе. Поиск камер сохраняет выбранный микроскоп.
Тестовые снимки не попадают в исследование или калибровку. Для автоматического
микроскопа доступна проверка камеры; перемещение образца пока не подключено.

Во вкладке «Калибровка» выберите микроскоп, источник изображения и цену деления.
Для любого микроскопа можно снять шкалу камерой или загрузить готовый снимок.
Нажмите «Рассчитать масштаб», проверьте изображение, укажите название и сохраните.
Показываются масштаб в мкм/пикс, число пикселей на деление, количество и
направление распознанных штрихов. Ручной ввод коэффициента находится
в дополнительном разделе. Сообщение «Калибровка сохранена» подтверждает запись;
изменённые данные помечаются как несохранённые.

Снимок и коэффициент относятся к выбранному микроскопу. При смене прибора
предыдущая шкала очищается с подтверждением, если снимок или коэффициент уже
получены. Перед созданием новой или открытием другой калибровки программа
предупреждает о несохранённых изменениях. Переключение вкладок сохраняет форму.

Штрихи могут идти горизонтально или вертикально. Помимо привычной шкалы на
светлом фоне проверяется контраст отдельных каналов: это помогает отделить
чёрные штрихи на прозрачной линейке с окрашенной основой и бликами. Обрезанная
начальная граница штриха исключается из расчёта. Для надёжного результата
снимайте не менее четырёх отчётливых штрихов, сохраняйте ровное освещение
и располагайте шкалу по горизонтали или вертикали.

Цена деления — физическое расстояние между соседними штрихами. Доступны
1, 2, 5, 10, 20, 25, 50, 100, 200 и 500 мкм, а также 1 мм (1000 мкм).
Для проверки обычной миллиметровой линейкой выбирайте «1 мм (1000 мкм)»,
если соседние распознаваемые штрихи соответствуют одному миллиметру.
Существующие калибровки «1 мкм» и «10 мкм» сохраняют прежний смысл.

Используется OpenCV 5 (`opencv-python-headless>=5.0,<6`). Белая обводка номеров
частиц и подписей шкалы строится по отдельной маске текста. Она сохраняет
читаемость на тёмных частицах и при уменьшении предпросмотра; контуры для
измерений и значения размеров от этой отрисовки не зависят.

## Подключение микроскопа и ручная съёмка

1. В «Настройках» выберите микроскоп слева или нажмите «Добавить».
   Найдите камеры, выберите устройство и включите видео. Отдельная кнопка
   «Снимок» фиксирует тестовый кадр; видео продолжает обновляться.
2. Для нового микроскопа укажите название и тип перемещения, затем нажмите
   «Добавить микроскоп». Для существующего сохраните выбранную камеру
   кнопкой «Сохранить привязку». Индекс вручную доступен в дополнительном разделе.
3. «Остановить» освобождает камеру. После перезапуска видеопросмотр включается
   вручную; запись микроскопа и привязка сохраняются.
4. В «Калибровке» выберите микроскоп и цену деления, снимите шкалу или загрузите
   готовый файл. Рассчитайте масштаб, проверьте результат, укажите название и сохраните.
5. В «Анализе» выберите микроскоп и его калибровку. Источник «Камера» позволяет
   добавлять кадры кнопкой «Снимок» при ручном перемещении образца. Источник
   «Загрузить файлы» доступен для любого микроскопа. Нажмите «Анализировать серию».
6. Откройте «Результаты»: сводка и таблица относятся ко всем кадрам серии.
   Линейные размеры указаны в мкм, площадь — в мкм². Таблица разбита на страницы
   по 50 частиц. В «Распределении» выберите параметр и целое число диапазонов
   от 2 до 100. Неверный ввод не заменяет построенный график.
7. Сохранить исследование можно из «Анализа» или «Результатов». Появляется
   подтверждение сохранения; новый расчёт требует нового сохранения.
   Перед созданием новой серии или открытием другой программа предупреждает
   о несохранённых изменениях, в том числе при переходе через «Исследования».

При смене микроскопа прежняя серия очищается с подтверждением, чтобы снимки
одного прибора не измерялись по калибровке другого. Смена калибровки возвращает
исходный снимок и требует повторного расчёта. Пока обновляются калибровки,
снимаются или загружаются кадры, действия с серией заблокированы.

Для нового расчёта масштаб берётся из подтверждённого контекста калибровки.
У сохранённых ранее исследований исторический коэффициент не записан отдельно:
их численные измерения доступны, но сегодняшнее значение калибровки не выдаётся
за масштаб исходного расчёта. Таблица показывает всю серию; связь отдельной
частицы с именем кадра в существующем формате данных не хранится.

Предпросмотр может иметь уменьшенное разрешение; снимки сохраняются в полном
разрешении, которое отдаёт камера. Кадры получают разные имена. Новый кадр,
удаление изображения или смена калибровки требуют повторного анализа перед
сохранением результатов. Новый снимок шкалы сбрасывает прежний коэффициент.
При переключении вкладки или исследования камера освобождается.

Если камера не открывается, проверьте кабель и индекс, освободите её в других
программах и подключитесь заново. После переподключения USB индекс может
измениться — повторите поиск и измените привязку в настройках. Поддерживаются
камеры, доступные OpenCV VideoCapture; для устройства с собственным SDK нужен
отдельный адаптер. Windows использует DirectShow.

## Автоматический стол XYZ

Основная плата — классическая Arduino Nano (ATmega328P), три драйвера A4988,
три концевика. Uno, Mega 2560 и DRV8825 можно выбрать в настройках. Скетч,
схема выводов и порядок настройки — [firmware/README.md](firmware/README.md).

1. В «Настройках» выберите автоматический микроскоп, привяжите камеру, сохраните
   параметры стола и COM-порт. До проверки инженером прошивка запрещает движение.
   Для проверки программы без оборудования выберите режим «Симулятор».
2. Подключите стол и нажмите «Найти ноль». После остановки/переподключения поиск
   нуля требуется заново. Координаты интерфейса — в импульсах STEP.
3. В «Калибровке» на этом микроскопе закрепите шкалу, укажите цену деления,
   название профиля и позиции Z через запятую. Мастер снимет и рассчитает каждую
   точку; проверьте снимки шкалы в сохранённом профиле. Между точками масштаб
   не интерполируется. Резкость и освещение проверяются перед запуском.
4. В «Анализе» выберите профиль, точное Z и сетку XY. Вся серия снимается на одном
   Z. Для другого масштаба начните новое исследование. После сетки калибровка
   выбирается автоматически; анализ и сохранение работают как обычно.

STOP доступен на панели и в верхней полосе во время задания. Готовые кадры
остаются после ошибки/отмены; неготовый профиль Z не активируется. Смена сессии
во время задания блокируется. Уход со вкладки, запустившей задание, останавливает
его. Для реального стола программный STOP дополняется физической защитой механики.

Автофокус, сшивка и исключение повторных частиц в перекрывающихся кадрах не
реализованы. Поле кадра отображается в мкм, шаг сетки задаётся в импульсах:
учтите импульсы/мм механики и выберите шаг без перекрытия. Настройка Z проводится
с эталоном, а рабочая съёмка использует сохранённый масштаб. После замены оптики,
механики или камеры создайте новый профиль. Снимок масштаба и координаты каждого
кадра сохраняются вместе с исследованием. Синтетические серии симулятора отмечены
как тестовые и не предназначены для реальных измерений.

## Проверки интерфейса для разработчика

Основные проверки логики не требуют браузера и дополнительных npm-пакетов:

```bash
node tests/gui/camera.test.js
node tests/gui/research.test.js
node tests/gui/stage.test.js
```

Для DOM-проверки установите jsdom 16.7.0 в отдельную папку и добавьте её
node_modules в NODE_PATH, затем выполните `node tests/gui/dom.test.js`.
Эта проверка использует поставляемый Vue и проходит настройки, съёмку шкалы,
накопление серии, анализ, сохранение и загрузку. Для Node 12 нужны параметры
`--harmony-optional-chaining --harmony-nullish`; для актуального Node они не нужны.

Автоматические проверки используют подмену физической камеры. На Windows
с реальным микроскопом дополнительно проверьте предпросмотр, разрешение,
съёмку шкалы и серии, отключение USB и повторное подключение. Сборка Windows
проверяется запуском PyInstaller и полученного приложения на Windows.

Для отдельной DOM-проверки автоматического режима:
`NODE_PATH=<папка/node_modules> node tests/gui/stage-dom.test.js`.
Она проверяет настройки Nano, подключение, остановку при уходе со вкладки,
поиск нуля, создание профиля Z и завершение сетки через тот же Vue-компонент.
